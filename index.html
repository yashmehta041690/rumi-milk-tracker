Install on your phone

After this app is hosted on a secure HTTPS address, add it to your home screen for an app-like experience.

iPhone: Open this app in Safari, tap Share, then choose Add to Home Screen.

Android: Open this app in Chrome and choose Install app or Add to Home screen from the browser menu.

After this app is hosted on HTTPS, install it from Safari. Pumping records are not sent to the hosting provider by this app.

Storage

This browser · local only

Records are stored in this browser on this device; this app has no app server or analytics. The hosting provider still serves app files and may log ordinary web request metadata. Browser storage is not encrypted medical storage; export backups regularly.
